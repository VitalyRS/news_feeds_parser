# 📰 News Collector — Деплой на Koyeb (Free Tier)

Этот каталог содержит адаптированную версию сборщика новостей для развёртывания на облачной платформе **Koyeb** с использованием бесплатного тарифа.

---

## 🏗️ Архитектура решения

1. **База данных**: Так как файловая система Koyeb является временной (ephemeral), для хранения новостей используется бесплатный управляемый **PostgreSQL** от Koyeb (вместо SQLite).
2. **Веб-сервер (FastAPI)**: Koyeb требует, чтобы веб-службы слушали порт. Приложение запускает легковесный веб-сервер, который отвечает на запросы здоровья платформы и предоставляет эндпоинт для запуска парсинга.
3. **Планировщик (Cron)**: На бесплатном тарифе Koyeb нет поддержки фоновых воркеров. Запуск сбора новостей раз в час инициируется внешним запросом от бесплатного сервиса **cron-job.org** на эндпоинт `/collect`.

---

## 🚀 Пошаговое развёртывание

### Шаг 1 — Создание базы данных PostgreSQL в Koyeb
1. Войдите в консоль [Koyeb](https://app.koyeb.com/).
2. Нажмите **Create Service** и выберите **Database**.
3. Выберите **PostgreSQL** (Free tier). Нажмите **Create**.
4. После создания скопируйте строку подключения из поля **Connection URI** (выглядит как `postgresql://...`).

### Шаг 2 — Деплой веб-службы на Koyeb
1. Создайте отдельный репозиторий на GitHub и поместите туда содержимое папки `koyeb`.
2. В панели управления Koyeb нажмите **Create Service** -> **Web Service**.
3. Подключите ваш GitHub-аккаунт и выберите созданный репозиторий.
4. В разделе **Environment Variables** (переменные окружения) добавьте:
   * **Key**: `DATABASE_URL`
   * **Value**: `<вставьте скопированную строку подключения PostgreSQL>`
5. Нажмите **Deploy**.
6. Дождитесь завершения сборки и скопируйте публичный URL вашего приложения (например, `https://your-app-name.koyeb.app`).

### Шаг 3 — Настройка расписания (Cron)
Чтобы скрипт автоматически запускался раз в час:
1. Зарегистрируйтесь на бесплатном сервисе [cron-job.org](https://cron-job.org/).
2. В панели управления нажмите **Create Cronjob**.
3. Заполните параметры:
   * **Title**: `News Collector Parser`
   * **URL**: `https://<имя-вашего-приложения>.koyeb.app/collect` (замените на ваш URL из Шага 2)
   * **Execution schedule**: `Every hour` (каждый час, на минуте `0`).
4. Нажмите **Create**.

Теперь раз в час `cron-job.org` будет будить ваш сервис на Koyeb, скрипт выполнит сбор новостей, сохранит новые записи в базу PostgreSQL, и сервис снова уйдет в спящий режим, сохраняя лимиты бесплатного тарифа.

## 💻 Локальный запуск для тестов

Вы можете запустить этот же код локально. Если переменная окружения `DATABASE_URL` отсутствует, скрипт автоматически переключится на локальную базу данных SQLite (`baza.db`).

### Установка зависимостей:
```bash
pip install -r requirements.txt
```

### Запуск веб-сервера локально:
```bash
python3 app.py
```
Приложение будет доступно по адресу `http://localhost:8000`. Вы можете вручную инициировать сбор новостей, перейдя по адресу `http://localhost:8000/collect`.

### Прямой запуск скрипта без веб-сервера:
```bash
python3 news_collector.py
```
